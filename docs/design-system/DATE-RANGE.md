# 日期范围规范示例

入口：`?view=design-system&component=datetime#library`。以用户提供的双月日历截图为结构参考，颜色、字体、边框、圆角采用系统参数。本轮仅更新规范示例，不替换公共DateRangeField及业务页面。

## 结构与外观

- 日期字段300×32px、8px圆角、16px日历图标，空值显示“开始日期 至 结束日期”；输入边框使用DCDFE6，打开/聚焦为单层主题焦点边框。
- 浮层704px宽，两个连续月份并排，中间1px分隔；白底、EBEEF5边框、8px圆角、系统反馈阴影。月份标题16/24、600字重；日期14/22、星期12/18。
- 周日为第一列，每个月展示六周；非本月补位日期灰色且不可选择。今天用主题红提示；起止日期使用28px主题红圆形、白字，区间用FFF1F2浅红连续高亮。
- 左侧提供上一年/上个月，右侧提供下个月/下一年，两个面板保持连续月份。底部显示选择步骤、清空和取消。
- 日历不显示滚动条，优先保留完整高度并避让视口边缘；640px以下双月纵排，宽352px且不超过视口减24px。极矮视口仍可触控、滚轮及键盘滚动，底部操作栏保持可见。
- 时间框与日期框等宽300px、32px高，窄容器同步收缩。左侧16px时钟，右侧清空；复用SelectField等宽下拉列表、8px圆角和系统阴影，选项36px高，选中主题红及600字重、悬浮灰底、按下浅红底。时间列表可滚动，滑块沿用系统#DCDFE6。

## 选择与恢复

第一次选择开始日期，第二次选择结束日期，完成后应用并关闭；移动到日期上可预览区间。结束日期早于开始日期时将该日作为新的开始日期，继续等待结束日；允许同一天范围。

打开时从已保存的开始日期所在月份显示，没有选值时显示Asia/Shanghai的当前月份。未完成的草稿不覆盖已保存范围；取消、Escape、点击外部或焦点离开时放弃草稿。清空同时删除起止值，保留独立的时间选择。起止日期使用YYYY-MM-DD，时间使用HH:mm；列表从00:00至23:45，每15分钟一个选项。点击立即保存并关闭，清空恢复空值。

时间列表支持上下键、Home/End、数字匹配及Enter确认；Escape、Tab和外部点击关闭，未确认的浏览不会修改时间。重新打开定位已选项，清空后焦点返回时间框。

## 键盘与实现边界

Enter/Space或向下键打开，焦点进入开始日期或今天。方向键移动1/7天，Home/End移动到本周首尾，PageUp/PageDown换月，Shift组合换年；跨显示范围自动翻页，Enter/Space选日。Escape取消并回焦，Tab可正常离开。

日期运算基于UTC纯日期，今天基于Asia/Shanghai；正确处理闰年与跨年。图标、状态和文字同时表达当前选择。独立的drp-*样式覆盖日历表格自身尺寸，避免继承规范文档普通表格的660px最小宽度。

实现为src/design/DateRangeExample.tsx及date-range-example.css；没有新增系统公共API。真实业务禁用日期、节假日及服务端校验需在后续接入时明确。回归命令`npm run check:date-range-ui`，实际结果见ACCEPTANCE.md。
