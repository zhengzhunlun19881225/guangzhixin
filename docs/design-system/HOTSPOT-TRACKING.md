# AI 热点追踪与事件演化（v1.0，本地业务模块）

生产入口`?view=portal`，位于右栏“AI 主动服务与智能提醒”正下方、最新通知之前。参考用户提供的热点时间线截图。生产消费者PortalNewsView，组件HotspotTracking.tsx，准备好的演示记录位于data/hotspotTracking.ts。

## 结构与视觉

- 复用pn-panel，白底16px圆角，面板间20px，左右沿用门户19px内边距、底部20px；标题16/24、600字重，红色标题标记与14px更多沿用系统。
- 第一层五个主题页签：人工智能、国产算力、某项政策、某家竞争对手、关注主题。默认竞争对手主题，选中红字/600和20×2px红线，其余14/22次级文字。窄容器仅主题行横向滚动，自动露出当前主题，不改变门户初始滚动位置。
- 关键变化行最小40px、8px圆角、系统灰背景。标题14/22半粗，摘要14/22辅助色，长文本单行省略并保留title；查看完整为真实入口。
- 分类为全部、已确认事实、媒体观点、AI分析，32px高胶囊，选中浅红底红字。主题切换恢复全部分类，分类或主题变化将模块时间线滚回顶部。
- 时间线红色6px节点、灰色虚线连接；时间12/18辅助色，事件标题14/22半粗，摘要12/18辅助色。分类/重大进展/来源数量为灰底4px圆角标签；查看为14px红色文字操作。时间线最大412px，溢出只滚动时间线。
- 详情、完整主题及全部主题共用ModalSurface，宽800px、16px圆角、业务标题18/28/600。正文14/22，来源材料用灰底8px圆角，头部关闭及底部关闭始终可达；小屏适应视口、正文独立滚动。

## 数据和行为

HotspotTopic具有id/label/change；HotspotEvent具有id/topicId/title/publishedAt/category/major/summary/detail/nextCheck/sources，来源记录具有id/title/type/excerpt。来源数量始终取sources.length，不硬编码数量；同一份事件数据用于面板、主题完整页和单条详情。事件按发布时间倒序、同时间保持准备数据中的顺序。

- 更多打开四个主题的概览，可关注及进入主题；查看完整展示当前主题全部三条进展，不受面板分类限制；关注主题标签聚合所有已关注主题的记录。
- 单条查看包含事件进展、后续关注和来源材料；来源是本地演示摘录，不创建无效外部链接或下载。列表→主题→事件可返回上层列表；Escape或关闭结束本次查看。
- 主题关注使用独立localStorage键guangxin-hotspot-follows，默认无关注，刷新恢复。损坏/未知id被忽略。保存失败显示“关注设置暂未保存，刷新后可能丢失。”并保留当前会话选择；取消关注后从关注聚合移除。
- 空关注展示暂无关注主题及选择入口；分类无记录展示暂无匹配进展。数目来自实际过滤结果，不提供虚假异步加载或空动作按钮。
- 主题方向键/Home/End并跟随焦点切换，分类为aria-pressed按钮；时间线为ol，时间为time。打开详情聚焦标题，关闭回原入口；原入口因取消关注消失时回当前主题页签。没有新增动画，兼容减少动态效果。

## 实现边界与验收

当前12条记录和材料均为本地演示，分类与事件合并结果为准备数据；没有联网抓取、自动去重、实时核验、后台关注任务或AI推理请求。材料中对企业/政策的泛称不作为真实经营信息或政策指引。关注保存仅对当前浏览器及站点有效，不代表账号级同步。

`npm run check:hotspot-ui`覆盖模块位置、主题与分类、完整查看/来源、关注及刷新/取消关注、保存失败、返回与焦点，以及两种UI模式×1920/1440/1280/390px布局、内部滚动和短屏弹窗。输出output/hotspot-tracking/verification.json与截图；不将独立测试上下文写入日常预览。
