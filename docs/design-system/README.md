## 已确认的基础规则

- 主正文 `--gx-text-primary: #03091B`；次级文字 `#4E5969`；辅助文字 `#878B99`；占位文字/弱提示 `#9CA3AF`。辅助灰不承载关键操作或主要内容。
- 悬浮文字 `#E60101`，焦点边框 `#CC0000`，菜单/工具悬浮底色 `#F4F6F8`；下拉选中浅红 `#FFF1F2`。选中与悬浮为独立状态。
- 页面主操作保留橙红品牌渐变与白字；系统弹窗主操作按最新确认改为纯红 `#FF0000`、白字，悬浮深红，不能变成红底红字。文件类型、图表系列、插画和图标品牌颜色属于内容色。
- 业务正文 `14/22px`；辅助信息 `12/18px`；区块标题 `16/24px`；AI 回答正文 `16/28px`；欢迎标题 `24/32px`、字重 600。不要把简报正文尺寸套到 AI 回答上。
- 默认搜索/日期/选择/按钮高度 32px，控件圆角 8px；菜单选项圆角 4px，面板圆角 16px，胶囊 999px。
- 数据页选择器 26px / 12px / 圆角 6px 属于紧凑变体；智能体创建框选择器统一为 32px；模型选择为胶囊。
- 间距以 4、8、12、16、20、24、32px 为主。20px 用于业务面板之间及简报内边距；10px 可用于字段内边距，不强制转换为 8px。
- 桌面头部 80px，侧栏 240px（折叠 64px），业务内容宽度上限 1660px，AI 对话上限 850px。小屏应降低列数或在数据容器内滚动。

## 状态与行为

所有新增交互组件评审默认、悬浮、选中、聚焦、禁用、加载、错误和空状态；不适用的状态注明原因。不能为了“覆盖所有状态”给静态标题增加点击行为。

- 文字操作悬浮变红；菜单/工具控件允许灰底。已存在的可点击业务卡片保留 2px 浮起与轻阴影，静态内容面板不浮起。
- 按钮加载保留名称并禁用重复提交；禁用状态不响应鼠标或键盘。
- 下拉无图标时不留图标列；菜单是独立浮层，自动避开屏幕边界。方向键移动、Enter/Space 选择、Home/End 到端点、Escape 关闭、Tab 关闭并继续焦点顺序，禁用项跳过。
- 下拉与账户菜单同白底、圆角、阴影和灰色悬浮底色。搜索清空后仍保留输入焦点；日期范围约束开始不晚于结束。
- 空状态区分“暂无内容”“暂无匹配结果”“暂未添加”；恢复操作必须真实有效。
- 表单错误保留输入并指出解决方式，使用 `role=alert`；成功提示使用 `role=status`。不要自动创建虚假成功状态。
- 重要操作通过明确的确认弹窗处理，取消不产生副作用。焦点进入弹窗，Escape 关闭，关闭后回到触发点。

## 业务模式

- 今日简报：固定列内头部、正文独立滚动；左右 20px 留白包含右侧滚动条；正文 14/22，段落与标题对齐。滚动条默认滑块色#DCDFE6，移入保留既有加深反馈。
- AI：首页四张能力卡使用各自业务文案；回答头像 30px，正文主色统一，操作栏不加横线。复制、预览与下载都对应当前回答。示例内容明确不代表实际数据查询/审批/提交。
- 门户资讯：两组轮播有独立滚动；区域悬浮/键盘聚焦才出现箭头；到端点禁用；标题悬浮变红。减少动态效果偏好下使用即时滚动。
- 应用管理：编辑态拖动排序，也支持 Alt + 左右键；保存才持久化，取消放弃草稿，存储失败保留草稿。
- 表格/目录：展开、选择、预览分别是明确操作；空结果保留筛选；长名称省略时保留完整标题；选择背景不替换文件图标颜色。
- 知识库团队列表、通讯录分类的选中态跟随主侧栏：浅红背景、主题红文字（`--gx-selected-text`）、字重400；悬浮选中项时保持选中底色，图标及箭头保留原色。真实页面即交互示例。
- 工作台/门户/IM 使用已提供的背景图，AI 内页保留现有较浅背景；浮动“常用/AI”切换在工作台各页存在。

## 文案、资源与可访问性

动作使用明确动词；避免“操作成功”而无上下文。未知值用“—”，数字 0 只代表已知为零。日期采用 YYYY-MM-DD，时间 HH:mm。示例与真实数据明确区分。

复用现有图标与插画资源。装饰图 `alt=""`，内容图片有说明，纯图标按钮必须有 `aria-label` 或可访问名称。状态不能只靠颜色；键盘应有可见焦点；动态效果遵循 `prefers-reduced-motion`。现有浅灰辅助文案尚未完成全量 WCAG 对比度审计，不能把本规范视为合规认证。

## 版本治理

修正说明或不改变外观的调整升补丁版本；新增组件/变体升次版本；改变默认样式、API 或页面密度升主版本。每次变更同时更新 token/组件、规范、示例及验收记录。未经记录的页面覆盖不能成为新的规范来源。

## v1.2.0 本地增量：资讯展示模式

AI 智能资讯、集团综合资讯在搜索框左侧各有卡片/列表图标按钮，两个模块独立，默认卡片。按钮组高 32px，单按钮 28×26px，选中使用浅红底和红色图标，悬浮使用系统灰底、红色图标。提供 title、aria-label、aria-pressed 和可见键盘焦点；Tab 定位，Enter/Space 切换。

切换保留当前分类、搜索文字及结果排序；列表采用左图右文：左侧图片 167×100px、圆角 12px，与右侧文案间距 16px；右侧标题16/24、字重400，标题后展示分类/精选标识，下方摘要 12/22、最多两行，底部日期与来源 12/18。标题悬浮变红，点击仍打开原资讯详情。每条高 100px、条目间距 32px；模块随结果条数自适应，最多完整展示 5 条（列表区上限 628px），第 6 条起在列表内部滚动，筛选变化回到顶部；空结果保持“暂无匹配资讯”与可清空搜索入口。列表不显示卡片轮播箭头。模式仅为当前页面状态，重新进入页面默认卡片，不新增浏览器持久化偏好。

两个模块使用同一个 NewsList 实现，数据、过滤与详情入口与卡片共用；实际示例入口为门户资讯页，未另建演示数据。头部空间不足时沿用分类换行布局。此增量只在本地更新。
