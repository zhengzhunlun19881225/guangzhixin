# 页面与组件盘点

盘点基线：2026-11-06 已发布系统。可搜索的完整页面清单由 `src/design/catalog.ts` 维护，规范页直接读取，避免两套页面名称漂移。

## 页面覆盖

| 领域 | 页面/场景 | 关键结构 |
| --- | --- | --- |
| AI | 会话首页、回答详情 | 能力卡、问题列表、模型选择、输入区、思考/操作栏、预览 |
| 工作台 | 常用首页 | 今日简报、待办、应用、最近表单、日程、浮动切换 |
| 智能体 | 智能体、技能 | 页签、分类、搜索、卡片、创建 |
| 文档 | 知识库列表、目录详情、云盘 | 树、文件表、搜索、日期、文件类型、文件操作 |
| 办公 | 待办中心、数字员工 | 表格筛选分页、空状态 |
| 门户 | 资讯、数据 | 轮播、提醒、新闻详情、统计卡、图表、紧凑筛选 |
| 协作 | IM 会话、通讯录 | 联系人、消息、输入区、组织树、人员卡 |

共 14 个页面/场景；回答详情和知识库目录需要在对应页面内进入，不是独立路由。

## 浮层与专业组件

| 组件 | 实现 | 状态/交互 | 定位 |
| --- | --- | --- | --- |
| 全局搜索 | SearchModal | 输入、清空、打开结果、关闭 | 专用业务组件 |
| 历史记录 | HistoryModal | 搜索、分类、分页、打开记录 | 专用业务组件 |
| 文档预览 | FilePreviewDrawer | 当前文档内容、关闭、下载 | 专用业务组件 |
| 应用管理 | ApplicationManager | 浏览/编辑、增删入口、拖动/键盘排序、保存/取消/失败 | 专用业务组件 |
| 我的日程 | ScheduleModule / ScheduleDialog / ScheduleFields | 七天周历、新建会议/事件、详情、人员搜索、附件、保存/取消/失败 | 专用业务组件；仅本地数据 |
| 简报祝福 | DailyBrief 内部原生 dialog | 语气切换、编辑、字数、生成、发送反馈 | 专用业务组件 |
| 云盘弹窗 | CloudDriveView 内部原生 dialog | 新建/重命名/删除确认/预览/发送 | 专用业务组件 |

| 新闻轮播 | NewsCarousel | 重置、边界、滚动、键盘、悬浮箭头 | 公共组件 |
| 菜单/搜索/日期 | SelectField / FieldControls | 选中、清空、键盘、越界定位 | 公共组件 |

## 本次公共组件提取

`UI.tsx` 新增 Button、PanelHeading、StatusBadge、EmptyState。保留原业务类名负责页面定位，公共组件负责语义、状态与通用外观。工作台标题五处、待办/日程标签、数字员工/云盘空态、应用管理保存/取消及简报按钮已经实际使用，不只存在于示例页。

未把文件表格、组织树、对话输入区强行改造成单一通用组件：它们的业务数据和操作不同，当前作为已登记的业务模式维护。

所有居中弹窗已接入 v2.0 统一结构槽：日程创建/详情/列表、订阅、应用管理、简报祝福、云盘五类、智能体/技能创建、资讯/提醒/目录详情、历史、全局搜索、PPT预览、IM资料/加成员/退出以及规范确认示例。文件预览抽屉仍按抽屉布局。
