# PPT模板输入模式（业务实现，仅本地）

入口：AI会话首页“制作PPT”，或输入区智能体选择器“PPT生成”。进入模式不发送消息，首页内容收起，输入框上方默认展开模板面板。底部“模板”可收起/展开；分类在当前模式内保留，重新进入恢复全部模板。

面板与输入框同宽，沿用850px会话上限；面板白底、16px圆角、语义边框。三套封面直接复用`public/assets/ppt-templates/`，不重绘。分类八项，已有三个实际模板；无模板分类显示空态，不补造模板。桌面三列，小屏内部横向滚动，选中外边框主题色50%，名称和勾为实色。预览为18/28标题标准业务弹窗。

选择模板保留当前输入，显示34×20缩略图、名称与可移除入口，保持面板展开。面板在PPT模式内不因点击输入框关闭；按钮/关闭/Escape均可收起。选择、预览、替换、移除及退出均处理焦点。退出模式恢复普通工具，保留文字并清除模板。独立PPT模式不影响智能写作原有PPT工具的插入文案行为。

发送前校验模板与主题，失败保留草稿；生成中复用原有停止/禁用机制。当前只有本地大纲示例，不生成PPT文件、不调用远程模型；回答明确该边界。小屏仅在本模式内收起侧栏，保留所有模板、模型与发送操作可访问。

来源：`AIChatView.tsx`、`AgentComposerTools.tsx`、`ppt-composer.css`、`data/pptTemplates.ts`与`conversationExamples.ts`。专项：`npm run check:ppt-ui`，输出`output/ppt-composer/`。
