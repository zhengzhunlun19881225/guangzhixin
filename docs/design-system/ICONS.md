# 图标资源规范 v3.4.0

入口：`?view=design-system&component=icon#library`。本轮仅规范评审，尚未替换系统图标。

## 来源、分类与配色

用户提供138个SVG，按图形去重保留133个：线性119、面性14。线性按中空轮廓、面性按实体主体判断，不依据SVG是否采用fill属性分类；默认24px，可切换16/20/24px，并搜索名称与别名。

普通图标使用主文字色#03091B，可切换主题红#FF0000；警告使用#FF7D00、提示使用#006DFF、事件使用主题红；渐变文档保留原有蓝紫色层次。原SVG字节不修改，保留viewBox，CSS遮罩着色保留镂空。资源缺失时等尺寸占位。

目录来自src/design/iconCatalog.json，来源路径与SHA-256保存在该文件。运行npm run docs:icons生成本文，npm run check:icons检查来源覆盖、字节哈希、别名和文档同步。用户桌面和下载目录中的原文件不删除、不改名。

## 接入边界

IconCatalog为规范内部预览，不新增公共图标API。原业务的lucide和品牌图标消费者保持原样。装饰图标不响应操作；图标按钮提供完整名称、禁用语义与键盘焦点。只有用户确认后才安排业务迁移。
