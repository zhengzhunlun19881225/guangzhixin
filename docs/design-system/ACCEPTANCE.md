- 旧 CSS 中仍保留历史布局覆盖及少量场景色；本次集中核心语义色，并未重写全部业务样式。
- 触屏拖动、全部移动端页面布局、其他浏览器兼容性未作为本版通过项。
- 企业数据和真实服务未接入，业务演示不能视为正式接口验收。
