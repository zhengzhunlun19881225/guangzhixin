# 差旅偏好与创建智能体（业务实现，仅本地）

## 差旅偏好

设置菜单及个人菜单的“差旅偏好”打开720px标准业务弹窗。标题18/28、字重600，白底16px圆角，表单控件32px、圆角8px，正文14/22；底部取消/保存36px、间距40px，主操作纯红白字。左右30px，窄屏20px与单列，长内容只在正文区滚动。

分组为常驻地、火车/动车、飞机和酒店，九个可清空的SelectField，列间距40px、字段间距16px。常驻城市初始广州，其余未选。选择框使用共用键盘菜单、焦点和顶层定位；不使用原生select。取消/Escape/关闭放弃草稿，保存才写入`guangxin-travel-preferences`。重新打开/刷新读取已保存值，包括主动清空值；损坏数据回退，写入失败显示错误且保留草稿。

“AI分析喜好”展开当前选择概览。当前未接入历史订单和AI服务，界面明确是按已有选择整理，不推断消费/出行习惯。保存提示四秒后消失，可关闭，不阻挡页面操作。弹框关闭回到设置或个人菜单触发器。

## 创建智能体

智能体列表“创建”进入与待办相同的完整内页，保留系统顶部导航，收起左侧主栏，返回与16/24标题放在左栏顶部，移除贯穿页面的横线及“本机配置”。编辑器白底16px圆角，桌面左右从顶部直接按30%配置、70%测试分栏；配置和测试独立滚动，配置按钮区固定于底部。700px以下纵向排列，配置与测试在页内滚动访问，底部操作不遮盖字段。小屏头部仅在本流程内排列为两行。

配置包括可更换头像、名称10字、简介20字、欢迎语1000字、最多5条预设问题（每条30字）、分类、模型、个人发布人、个人/组织/通用权限与设定描述1000字。字段32px、白底浅边框；文字域支持调整高度。必填名称、简介和设定描述在发布和生成测试时共同校验，错误14px以下辅助层级，首个错误字段聚焦。权限使用32px灰底白色选中分段，原生Radio键盘语义保留。头像选择使用下述图片设置，旧版线条图标仍可读取。

“一键完善”按名称/简介追加可编辑的职责与边界草稿，保留原设定，不声称调用AI；空信息/字数已满给出提示。“生成测试”抓取当前配置快照，右侧展示欢迎语、预设问题和本地对话预览；后续修改出现重新生成提示。测试支持输入/Enter发送（Shift+Enter换行、输入法组合不发送）、预设问题发送和清空。右侧明确“本地预览”，回应说明未连接模型，不伪装真实模型推理。

“发布”保存至`guangxin-custom-agents`，返回列表显示可再次编辑的本机卡片；已有配置使用“保存”更新同一ID。权限仅为配置字段，不向组织或服务器授权。保存失败留在当前页并保留配置与测试。返回有修改时确认放弃，取消继续编辑；刷新/关闭页有未保存修改使用浏览器离开保护。返回列表恢复触发入口焦点。

技能列表仍使用既有创建弹框，未将技能套入本次智能体编辑流程。数据契约位于`data/personalSettings.ts`。专项`npm run check:personal-ui`沿用Playwright环境变量，证据位于`output/playwright/personal-features/`。

## 智能体图片设置

创建页头像打开1040px标准业务弹框，左侧4×4共16张用户提供预设图片，右侧等宽上传区域；间距30px。上传图标、两行说明整体水平和垂直居中。标题18/28、普通正文14/22，取消/确定为36px、主题红主按钮。700px以下两栏纵排，正文独立滚动、底部操作保持可见。预设图片来源和裁切说明位于public/assets/agent-avatars/README.md。

点击预设仅更改弹框草稿；支持点击上传、拖拽上传与重新上传，单次一张PNG/JPG/JPEG，最大5MB。上传后展示原图与正方形裁剪框：拖动移动，八个控制点缩放；方向键微调，Shift加速，裁剪始终限制在图片内。蓝色控制点属于图片编辑工具内容色，按钮、选中与焦点沿用主题红。重置裁剪恢复居中60%范围；再次编辑已保存图像时默认完整范围，未改动确认不重新编码。

确定才实际裁剪（最长256px正方形）、更新创建页头像；取消/关闭/Escape/遮罩不修改原头像，回到头像入口焦点。预设与上传选中互斥，切换保留本次上传；读图/裁剪有加载与错误提示，失败保留先前选择，离开弹框后旧异步结果不会写回。发布后配置、测试快照、列表卡片和再次编辑共用同一图像。avatarImage只接受预设路径或有限长度PNG/JPEG data URL，不读取远程头像；旧icon字段保留兼容。原始上传图只保留当前弹框内存，保存的是裁剪结果。

专项npm run check:agent-images覆盖16张图片加载、鼠标/键盘裁剪及真实像素、错误文件/大小、取消草稿、旧数据迁移、持久化和两种模式四尺寸。输出output/playwright/agent-images/。

## 法智小新输入工具

首页点击“法智小新”选择模式，不发送卡片名称。该模式移除四个快捷智能体及通用工具/切换胶囊，底部使用与智能问答完全相同的已选胶囊，名称为“法智小新”、共用图标与切换面板；右侧×的可访问名称为“取消法智小新”，保留上传、联网、模型与输入主操作。点击×恢复普通四个快捷入口，保留草稿与已有对话，焦点返回输入框。生成中先停止，工具与取消禁用，避免重复提交；普通模式、PPT模式和智能写作保持各自工具。

以上都是业务模式，不增加59项公共组件数量，不进入完整规范下载的三个模块。未连接真实差旅订单、模型或智能体发布服务。
