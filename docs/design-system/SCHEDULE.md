# 我的日程与新增表单（v1.1.0 本地增量）

参考：用户提供的《工作台1备份 2/3/4/5.png》。生产入口 `?view=dashboard` 右下角；“新增日程”菜单打开会议或事件表单，列表项打开详情，“更多”打开当前范围的全部日程。

## 模块布局与行为

- 保留工作台三栏结构，日程替换原月历；其他模块不在本次改动范围。
- 周一至周日七天。以浏览器当天为初始日期，前后按钮切换整周，点击日期筛选，跨天事项在相交日期展示。周范围可访问名称、日期完整 title 避免仅显示日号时丢失月份。
- 日程周历按最新确认使用红底白字选中日期；悬浮标题红色。日期支持左右键和 Home/End，选中按钮为当前键盘停靠点。
- 头部新增按钮与范围选择高 26px；范围包括我的日程、我发起的、公开日程。当前用户为本地演示用户张嘉嘉。
- 日程卡片高 78px、圆角 16px、间距 8px；标题 14/22，时间 16/22，元信息 12/18。单行省略可通过 title 或详情查看全文。仅实际有附件时显示附件标记。
- 空日期提供暂无日程说明；加载时禁止新增，读取失败可以重试。列表独立滚动，滚动条默认滑块色#DCDFE6，悬浮保留既有加深反馈。

## 表单结构与尺寸

弹窗宽 710px、圆角 16px；水平内边距 30px。字段双栏，列间距 50px、行间距 22px。字段默认高 32px，标签 14/20，说明/内容文本域初始高 60px。底部取消/确定按钮高 36px、最小宽 78px、间距 40px，属于该参考表单的业务例外。主按钮沿用系统白字橙红渐变，菜单沿用白底、灰底悬浮、红色文字。

低于 600px 使用单栏和 20px 水平内边距；弹窗限定视口高度，内容滚动而底部按钮保持可用。关闭按钮与 Escape 取消，关闭后回到触发点。提交中禁用表单与关闭，防止重复提交。

| 表单 | 必填项 | 可选项 |
| --- | --- | --- |
| 新建会议 | 会议名称、开始/结束时间、类型、主持人、至少一位与会人 | 线下地址或线上链接、告知人、提前提醒、可见范围、描述、附件 |
| 新建事件 | 事件名称、开始/结束时间、事件内容 | 安排他人、告知人、提前提醒、可见范围、描述、附件 |

- 名称最多 20 字符，事件内容/描述最多 200 字符，实时计数。不复制参考图中不准确的字数。
- 结束必须晚于开始；线上链接填写后必须为有效 HTTP(S) URL。地址与链接依照参考作为可选字段，线上/线下切换保留各自草稿。
- 主持人可搜索并单选；其他人员多选、移除。人员来自本地演示名单，不假装搜索了企业通讯录。方向键、Home/End、Enter、Escape 可操作人员列表。
- 错误以字段内文字呈现并聚焦首个错误，保存失败保留草稿；取消不保存人员、附件或其他字段。
- 附件支持点击选择、拖入、删除、按原文件下载。只在确定后持久化，附件列表显示实际文件名与大小。PDF 图标复用云盘资产，其余类型使用既有图标库。

## 组件与数据接口

```tsx
<ScheduleModule />
<ScheduleDialog kind="meeting" day="2026-11-06"
  onClose={closeDraft} onSave={saveSchedule} />
<PeopleField label="与会人" multiple value={participants}
  onChange={setParticipants} />
```

`ScheduleModule` 负责加载、筛选、日期选择及对话框。`ScheduleDialog` 管理独立草稿与校验，`onSave(item): Promise<void>` 成功后才关闭，失败必须抛错以显示重试提示。`ScheduleFields` 仅用于日程人员及会议时间，暂不作为全系统表单引擎。

`src/data/schedules.ts` 保存数据类型与 IndexedDB 读写。数据库 `guangxin-schedules` / store `items` 持久化新建记录与真实 Blob；演示的三条初始日程在当天生成，不写入数据库。数据与浏览器/站点来源绑定，刷新保留，清除站点存储会清除记录。

这是本地演示实现：提前提醒、可见范围和人员是本地字段及筛选依据，不代表服务器定时提醒、企业权限控制、会议邀请或对他人的通知。没有调用 IM、邮件或外部日历。编辑、删除、周期日程与真实企业接口不属于本次新增表单范围。

## 验收

执行类型检查、规范静态检查、构建，以及 `check:ui` 和 `check:schedule`。后者使用独立浏览器上下文，测试数据不进入用户日常预览；覆盖日期/周切换、表单校验、人员、类型切换、附件字节一致性、刷新持久化、存储失败恢复、取消、键盘、详情及范围筛选。
