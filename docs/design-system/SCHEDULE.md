# 我的日程、完整日历与新增表单（v1.2.0 本地增量）

参考：用户提供的《工作台1备份 2/3/4/5.png》。生产入口 `?view=dashboard` 右下角；“新增日程”菜单打开会议或事件表单，列表项打开详情，“更多”进入完整日历页面，初始为卡片所选日期所在的周。

## 模块布局与行为

- 保留工作台三栏结构，日程替换原月历；其他模块不在本次改动范围。
- 周一至周日七天。以浏览器当天为初始日期，前后按钮切换整周，点击日期筛选，跨天事项在相交日期展示。周范围可访问名称、日期完整 title 避免仅显示日号时丢失月份。
- 日程周历按最新确认使用红底白字选中日期；悬浮标题红色。日期支持左右键和 Home/End，选中按钮为当前键盘停靠点。
- 头部新增按钮与范围选择高 26px；范围包括我的日程、我发起的、公开日程。当前用户为本地演示用户张嘉嘉。
- 日程卡片高 78px、圆角 16px、间距 8px；标题 14/22，时间 16/22，元信息 12/18。单行省略可通过 title 或详情查看全文。仅实际有附件时显示附件标记。
- 空日期提供暂无日程说明；加载时禁止新增，读取失败可以重试。列表独立滚动，滚动条默认滑块色#DCDFE6，悬浮保留既有加深反馈。

## 更多：完整日历页面

参考用户《待办备份 3.png》，生产入口 `?view=dashboard` → 我的日程 → 更多。保留系统顶部导航，内容为独立的全高日历面板；返回恢复工作台、所选日期和范围，并聚焦“我的日程更多”。面板16px圆角，桌面外距左右/下方20px，工具栏32px控件；日期页签为灰底、选中白底的系统分段样式，左栏主题红选中。新建沿用页面渐变按钮，业务表单沿用纯红按钮。

- 默认周视图，周一至周日；支持日/周/月以及前后日期、本周/今天/本月。月切换保留日号，目标月不足时夹至月末。标题显示完整日期范围；月格包含相邻月，点击日期进入日视图。日期结束为半开区间，午夜结束的日程不进入下一天。
- 周/日时间网格覆盖00:00–24:00，60px/小时，初始滚动至08:00；日期栏及时间轴固定在各自滚动方向。跨天记录按日截断，同时间段重叠记录并排，当前日期灰底、当前时间红线且每分钟更新。点击记录复用真实详情，长标题可通过title或详情查看。
- 我的视图复用“我的日程 / 我发起的 / 公开日程”；部门视图按补充参考展示8位演示成员，支持全选/半选和逐人筛选，右侧为成员×日期矩阵；成员头像44px、成员列188px、行高至少108px，日期头和成员列在滚动时固定。只显示与该成员关联的本地公开日程，空记录保留网格；日/周/月分别显示1天/7天/本月全部日期，今日红线按当天时间比例定位。他人视图从既有演示人员中选择，仅筛选此人参与的本地公开日程。类型为实际模型的会议、事件、出差，不提供无数据源的任务。
- 新建复用会议/事件菜单及ScheduleDialog，真实写入同一IndexedDB；保存后跳转到开始日期，并恢复“我的视图 / 我的日程 / 全部类型”，保证新记录可见。返回工作台及刷新后读取同一记录；取消不写入。读取失败保留重试入口，未就绪时禁用新建。
- 日历按时间范围导航，无列表分页。空范围保留网格并提示“当前范围暂无日程”；辅助信息显示当前范围的实际记录数，跨天记录不重复计数。
- 键盘：分段方向键、Home/End；新建菜单方向键、Home/End、Escape；筛选复用SelectField。进入页面聚焦返回，关闭详情/表单恢复原触发器；月格进入日视图后聚焦“日”页签。滚动容器可Tab聚焦。
- 桌面侧栏240px，1500px以下200px；1100px以下日期范围换行。700px以下视图筛选改为横排，日历网格在自身容器内横向滚动并定位到所选日，页面本身不横向溢出。减少动态效果时无额外动画。

`ScheduleCalendar` 为业务组件，接收 items/day/onDay、scope/onScope、ready/error/onRetry、onBack/onOpen、newControl/notice/savedId；过滤、模式和日期网格在组件内，读写及对话框由ScheduleModule复用。ScheduleDepartment复用系统原生复选框样式，实现全选半选和成员日期矩阵；演示名单来自用户补充截图（scheduleDepartment.ts），不表示接通企业组织及权限服务。名单同步进入日程人员选择，公开记录按发起人/主持人/参与人/告知人关联；同条记录在多成员多日期显示时统计不重复计数。WorkbenchDashboard负责完整页与工作台的切换。未新增公共组件契约，也未修改59项组件清单。

## 表单结构与尺寸

弹窗宽 710px、圆角 16px；水平内边距 30px，标题 18/28px、600 字重。字段双栏，列间距 50px、行间距 22px。字段默认高 32px，标签 14/20，说明/内容文本域初始高 60px。底部取消/确定按钮高 36px、最小宽 78px、间距 40px，属于该参考表单的业务例外。主按钮沿用系统弹窗纯红白字，菜单沿用白底、灰底悬浮、红色文字。

低于 600px 使用单栏和 20px 水平内边距；弹窗限定视口高度，内容滚动而底部按钮保持可用。关闭按钮与 Escape 取消，关闭后回到触发点。提交中禁用表单与关闭，防止重复提交。

| 表单 | 必填项 | 可选项 |
| --- | --- | --- |
| 新建会议 | 会议名称、开始/结束时间、类型、主持人、至少一位与会人 | 线下地址或线上链接、告知人、提前提醒、可见范围、描述、附件 |
| 新建事件 | 事件名称、开始/结束时间、事件内容 | 安排他人、告知人、提前提醒、可见范围、描述、附件 |

- 名称最多 20 字符，事件内容/描述最多 200 字符，实时计数。不复制参考图中不准确的字数。
- 结束必须晚于开始；线上链接填写后必须为有效 HTTP(S) URL。地址与链接依照参考作为可选字段，线上/线下切换保留各自草稿。
- 主持人可搜索并单选；其他人员多选、移除。人员来自本地演示名单，不假装搜索了企业通讯录。方向键、Home/End、Enter、Escape 可操作人员列表。
- 错误以字段内文字呈现并聚焦首个错误，保存失败保留草稿；取消不保存人员、附件或其他字段。
- 附件支持点击选择、拖入、删除、按原文件下载。只在确定后持久化，附件列表显示实际文件名与大小。PDF 图标复用云盘资产，其余类型使用既有图标库。

## 组件与数据接口

```tsx
<ScheduleModule onMore={(day, scope) => openCalendar(day, scope)} />
<ScheduleModule expanded initialDay="2026-11-07"
  initialScope="我的日程" onBack={returnToDashboard} />
<ScheduleDialog kind="meeting" day="2026-11-06"
  onClose={closeDraft} onSave={saveSchedule} />
<PeopleField label="与会人" multiple value={participants}
  onChange={setParticipants} />
```

`ScheduleModule` 负责加载、筛选、日期选择及对话框。`ScheduleDialog` 管理独立草稿与校验，`onSave(item): Promise<void>` 成功后才关闭，失败必须抛错以显示重试提示。`ScheduleFields` 仅用于日程人员及会议时间，暂不作为全系统表单引擎。

`src/data/schedules.ts` 保存数据类型与 IndexedDB 读写。数据库 `guangxin-schedules` / store `items` 持久化新建记录与真实 Blob；演示的三条初始日程在当天生成，不写入数据库。数据与浏览器/站点来源绑定，刷新保留，清除站点存储会清除记录。

这是本地演示实现：提前提醒、可见范围和人员是本地字段及筛选依据，不代表服务器定时提醒、企业权限控制、会议邀请或对他人的通知。没有调用 IM、邮件或外部日历。编辑、删除、周期日程与真实企业接口不属于本次新增表单范围。

## 验收

执行类型检查、规范静态检查、构建，以及 `check:schedule` 和 `check:schedule-calendar`。表单回归使用独立浏览器上下文，测试数据不进入用户日常预览；覆盖日期/周切换、表单校验、人员、类型切换、附件字节一致性、刷新持久化、存储失败恢复、取消、键盘、详情及范围筛选。

完整日历专项覆盖原始/规范两种模式，1920、1440、1280、390px宽度，进入/返回、焦点、日周月、日期与类型/范围/人员筛选、跨天及午夜边界、重叠分列、月末翻页、新建共享与刷新持久化、失败重试和滚动。输出 `output/schedule-calendar/verification.json` 与截图；测试采用独立浏览器上下文。
